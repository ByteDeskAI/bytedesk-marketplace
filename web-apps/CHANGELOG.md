# Changelog

## 0.2.0 - 2026-09-19

- Connected the Web Apps workspace to Gateway's typed discovery, creation, conversation, service, preview, log, and sharing operations.
- Added opaque creation contexts, small reference and chat attachments, queued messages, explicit plan approval, service controls, password share creation and revocation, and periodic background-state refresh.
- Added `envFrom` to the marker schema so applications can select host environment variables by name without storing secret values in `.bytedesk-webapp.json`.

## 0.1.0 - 2026-09-19

- Add the Web Apps project view and Create Web App directory action declarations.
- Add owner-local workspace and creation panels with application selection, empty and
  startup states, responsive Chat and Preview panes, service controls, logs, and stop
  controls.
