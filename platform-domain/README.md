# platform-domain

Bounded-context proof operators — DBA, tool actions, Office workflows, DevProjects, remote gateway.

Install:

```
/plugin install platform-domain@bytedesk
```

Bins forward to the platform checkout via `BYTEDESK_REPO_ROOT` / `CLAUDE_PROJECT_DIR`. `scripts/dev/workflow.mjs` remains in the platform repo (ADR-0058).
