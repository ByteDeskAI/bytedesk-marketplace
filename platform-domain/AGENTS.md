# Platform Domain

Bounded-context proof operators — DBA, tool actions, Office workflows, DevProjects, remote gateway.

This plugin works across Claude Code, Codex, and grok-cli. Claude Code loads it via `.claude-plugin/plugin.json`; Codex via `.codex-plugin/plugin.json`; grok-cli and other AGENTS.md-aware agents read this file.

- **bytedesk-dba** (skill) — ByteDesk database architect skill.
- **bytedesk-devproject-domain-operator** (skill) — ByteDesk DevProject custom-domain operator.
- **bytedesk-devprojects-sandbox-refresh** (skill) — ByteDesk DevProjects sandbox refresh and validation operator.
- **bytedesk-maya-workflow-router** (skill) — Deterministic Maya Office-chat workflow routing validation.
- **bytedesk-remote-gateway-operator** (skill) — ByteDesk remote-gateway operator.
- **bytedesk-tool-action-engineer** (skill) — ByteDesk Tool Action Pattern engineer.
- **bytedesk-workflow-epic-integrator** (skill) — Integration manager for large ByteDesk workflow-system epics with many parallel agents or goal docs.
- **bytedesk-workflow-runtime-smoke** (skill) — End-to-end runtime proof for ByteDesk Office workflow changes.
