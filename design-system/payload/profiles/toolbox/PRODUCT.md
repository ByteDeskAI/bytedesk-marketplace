# ByteDesk Toolbox — Product Direction

## Register

product

## Product purpose

ByteDesk Toolbox is the desktop home for discovering, installing, updating, and
understanding the applications in the ByteDesk ecosystem. It stays close at hand in
the system tray, keeps application state current through `get.bytedesk.ai`, and makes
the next safe action obvious without becoming a permanent dashboard.

JetBrains Toolbox is a workflow reference for installed-versus-available organization,
update coordination, and release visibility. It is not a visual reference. Toolbox
uses ByteDesk identity and its own interaction personality.

## Users

- Anyone evaluating or installing publicly available ByteDesk applications.
- Signed-in customers whose account unlocks entitled applications or release channels.
- Developers and operators who need precise versions, freshness, progress, and failure
  details without managing each application separately.

## Product promises

1. Public applications remain useful before sign-in; entitlement changes availability,
   never the honesty of what is shown.
2. Installed version, available version, freshness, and update consequence are explicit.
3. Bulk actions remain inspectable and individual applications remain controllable.
4. Background presence is quiet; attention is requested only when the user can act.
5. Simulated, unavailable, stale, and live information are visibly distinct.

## Primary journeys

- See installed applications and pending updates at a glance.
- Update one application or review and start `Update all`.
- Discover public and account-entitled applications without mixing access state with
  operational health.
- Expand release notes, version history, and update activity without leaving the shelf.
- Change update policy, account state, launch behavior, and visual personality.

## Voice

Calm, direct, and operational. Prefer short verbs, exact versions, and plain-language
consequences. Celebrate completion briefly; explain waiting and failure without blame.

## Success criteria

A user can open the tray window, understand whether the catalog is current, identify
what is installed or available, and start the intended update action in seconds. A
failed or gated action always states why and what can be done next.

## Anti-references

- JetBrains branding, cube imagery, gradients, typography, or component styling.
- A promotional app store that obscures versions, access, or update consequences.
- A telemetry-heavy operations dashboard as the only runtime personality.
- Decorative agent imagery, fake terminals, or activity that implies work not occurring.
