# Agent Memory - Product Direction

## Purpose

Agent Memory is durable, permissioned organizational memory for fleets of AI
agents. The service, development playground, and in-repository public site must
make ownership scopes and authorization consequences understandable without
pretending a vector store is a trust model.

## Users and promises

- Operators define and inspect memory models, compartments, policies, and storage.
- Agent developers integrate through real REST, MCP, SDK, and schema contracts.
- Evaluators understand organization, department, agent, customer, and initiative
  boundaries before deployment.

Every recalled or stored item retains its scope. Denials, unavailable storage,
and partial results remain explicit.

## Voice

Calm, technical, and evidence-led. Use real addresses, schema names, policy
results, and tool calls. Never fabricate memory, scale, customer proof, or access.
