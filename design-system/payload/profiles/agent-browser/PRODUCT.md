# Agent Browser - Product Direction

## Purpose

Agent Browser is a high-performance browser runtime for agents. Its governed UI
surfaces are API-adjacent: live session viewing and takeover, desktop connection,
identity creation, and demonstrable task evidence. A general dashboard is not a
current product surface.

## Users and promises

- Agent developers need an honest view of session, profile, connection, and task
  state without hiding the API contract.
- Operators need to observe or take over a persistent browser safely.
- Every visible action distinguishes observation, agent control, and human control.

## Voice

Fast, exact, and instrument-like. Prefer session IDs, connection facts, timestamps,
and evidence over anthropomorphic claims about what the browser “thought.”
