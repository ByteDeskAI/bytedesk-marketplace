# __APP_NAME__

A Next.js App Router site wrapped in the ByteDesk family design system.

Generated by `create-bytedesk-site` from
[`ByteDeskAI/design-system`](https://github.com/ByteDeskAI/design-system).

## First run

```bash
git submodule update --init --recursive
npm install
npm run build
```

`npm run dev` serves the site locally; `npm run build` emits a static `out/`.

## Where the design system comes from

`ByteDeskAI/design-system` is mounted as a pinned git submodule at
`.context/design-system`. It carries three things at one commit:

- **Tokens** — `.context/design-system/tokens/css/bytedesk.css` (the `--bd-*`
  value layer) and `tokens/tailwind/theme.css` (the Tailwind v4 adapter). Both
  are `@import`ed at the top of `src/app/globals.css`.
- **The design profile for this site** — `.context/design-system/profiles/__SLUG__/`
  (`DESIGN.md` + `PRODUCT.md`), which is also this repository's
  `IMPECCABLE_CONTEXT_DIR` (see `.envrc`).
- **Shared foundation** — `.context/design-system/DESIGN.md`.

The submodule is **read-only** from here. Design changes land upstream in
`ByteDeskAI/design-system`, then this repository re-pins:

```bash
git -C .context/design-system fetch origin && git -C .context/design-system checkout <sha>
git add .context/design-system && git commit -m "chore(design): re-pin design system"
```

## House rules

1. **Consume `--bd-*`; never restate a literal.** A hex code in this repository
   is drift. If the value you want is not a token, that is a foundation change
   and it lands upstream first.
2. **The product accent is declared once**, as `data-bd-product="__ACCENT__"` on
   `<html>` in `src/app/layout.tsx`. Components read `--bd-accent`.
3. **The accent is identity, not status.** Semantic state uses
   `--bd-success` / `--bd-warning` / `--bd-danger`, and status is always a dot
   **plus a word** — never colour alone.
4. **Content lives in `src/content/`**, typed and colocated. Components render
   it; they do not inline copy.
5. **Extend the shared vocabulary in `globals.css`** before adding new CSS.

## Layout

```text
src/
  app/
    globals.css   # token imports + the local @theme alias root + shared classes
    layout.tsx    # family chrome wrapper, product accent, fonts, metadata
    page.tsx      # starter home page, reads src/content/site.ts
  components/
    Header.tsx    # family chrome
    Footer.tsx    # family chrome
  content/
    site.ts       # typed site content — replace every placeholder
```

## Design authority

Read in this order before making user-facing changes:

1. `.context/design-system/DESIGN.md` — shared foundation
2. `.context/design-system/profiles/__SLUG__/DESIGN.md` — this site's profile
3. `DESIGN.md` — local exceptions only
