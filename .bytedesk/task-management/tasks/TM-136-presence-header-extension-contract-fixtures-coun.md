The gateway terminal header must show slot queue, unread mailbox depth, agent state and current task per pane. Frozen Presence v1 carries none of them. The frozen validator settles what that costs: validate_presence.py has NO key whitelist (it rejects only ten named keys per agent), so additive keys pass it unchanged — but closed vocabularies are enforced by exact membership, so a new repoRole or runRole VALUE fails. Additive keys are not a change to the wire format; opening a closed vocabulary is. Run this as TM-128 was run, and make the producer depend on it rather than race it.
