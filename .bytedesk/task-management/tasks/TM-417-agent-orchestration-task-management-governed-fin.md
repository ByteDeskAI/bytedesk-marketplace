- topology/lib/management.mjs:154 (observedNativeWorker) requires `workflowRunId === "topology:" + nativeRunId`, so `ao-topology manage report --task TM-016` fails: `TOPOLOGY_MANAGEMENT_WORKER: Canonical workflow and native task run IDs differ.`
