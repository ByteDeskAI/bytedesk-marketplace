TM-127 disabled the tmux doorbell: every delivery reports { rang: false, notification: 'durable-pending' } because 'pane liveness proves neither an empty composer nor a safe tool-input state'. So an idle agent never wakes up. Replace it with an observed state machine in a new topology/lib/delivery.mjs: held / not-typed / typed-unsubmitted / submitted / engaged / submitted-inert / processed / escalated. The discrimination needs one new per-provider field (composer.empty_tmux_pattern) because deliverPointer's occurrence count already proves RECEIVED and the composer-empty check proves SUBMITTED. Engagement is pane.log byte growth — zero model turns, no ack command in the hot path.
