2026-09-24: after TM-214 landed, the lead could not close the worker tmux session tm214 it had started by hand; even a read-only capture of that pane was refused by the Claude Code auto-mode safety check, and the operator had to kill it. Root cause is the ad-hoc launch: the worker was not started through ao-topology (manage assign/dispatch), so no ownership record exists and manage cleanup cannot prove it may stop it. Fix: give the lead one supported path to start a worker for an admitted task that records ownership (session, pane, pid, start time) and one to stop it (manage cleanup or a dedicated stop verb) that checks ownership + idle + collected results before closing. Document it in docs/repository-leads.md so leads never launch workers ad hoc.
