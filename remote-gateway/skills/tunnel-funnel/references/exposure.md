# Optional public exposure

Install is **private-first** (`127.0.0.1`). Public access is optional on all platforms:

| Platform | Common options |
|----------|----------------|
| Linux | Tailscale Funnel, Cloudflare Tunnel, reverse proxy |
| macOS | Tailscale Funnel, Cloudflare Tunnel |
| Windows | Tailscale Funnel, Cloudflare Tunnel |

Do not expose without TOTP (and preferably approval).
