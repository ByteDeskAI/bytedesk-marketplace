# Recommended concept types (coding agents)

Open vocabulary — OKF does not register types. These are defaults for this plugin:

| Type | Use for |
|------|---------|
| Architecture | System shape, boundaries, data flow |
| Decision | ADR-style choices (why X not Y) |
| API | HTTP/RPC/event contracts |
| Module | Package or service ownership |
| Runbook | Ops steps, incident response |
| Onboarding | Getting started for humans/agents |
| Domain Concept | Business language |
| Playbook | Repeatable engineering workflows |
| Metric | Definitions (link Attested Computation when needed) |
| Reference | External docs, mirrored notes |
| Attested Computation | Blessed SQL/scripts (storage only in v0.1) |
